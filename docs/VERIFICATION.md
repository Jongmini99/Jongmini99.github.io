## 디자인 개편 (2026-11-16)

레퍼런스 분석 후 승인된 계획에 따라 홈을 한 페이지 구성으로 바꿨다. 어두운 톤과 블루 포인트 색은 유지했다.

- 홈: 히어로(2단, 원형 비주얼) → 대표 프로젝트 강조 섹션(네이비) → 프로젝트 타일 → 소개 → 이력 및 성과 → 연락하기. 메뉴는 섹션 앵커로 이동하고, 스크롤 위치에 따라 현재 메뉴를 표시한다.
- `/about/`, `/contact/`: 홈의 `#about`, `#contact`로 이동시킨다(noindex, sitemap 제외).
- 프로젝트 목록·상세: 기존 섹션 구조 유지, 새 디자인 규칙(큰 제목, 둥근 카드, 알약 버튼) 적용.
- 임시 이미지: `public/uploads/images/temp/` (권장 크기 표기). 실제 이미지로 교체 후 삭제한다.
